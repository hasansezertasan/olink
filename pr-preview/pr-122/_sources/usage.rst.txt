Usage
=====

As a library
------------

To use ``olink`` in a project:

.. code-block:: python

   import olink

As a command-line tool
----------------------

To use ``olink`` as a command-line tool:

.. code-block:: sh

   olink version
   olink info

As a TUI
--------

To launch the terminal user interface:

.. code-block:: sh

   olink-tui
